# 🎓 ربات سفارش پروژه دانشگاهی (تلگرام)

ربات سفارش‌گیری تلگرام — **همه‌چیز داخل خود ربات انجام می‌شود** (بدون سایت و مینی‌اپ).

## ✨ امکانات

### مشتری
- 📋 **ثبت سفارش**: انتخاب دسته → توضیحات → آپلود فایل مدارک (عکس، PDF، Word)
- 📂 **سفارش‌های من**: لیست و جزئیات هر سفارش (وضعیت، مبلغ، پرداخت‌ها)
- 💳 **پرداخت دستی (کارت به کارت)**: نمایش شماره کارت و مبلغ → مشتری عکس رسید می‌فرستد → مدیر تأیید/رد می‌کند
- 👥 **باشگاه مشتریان**: لینک معرف اختصاصی (`t.me/Bot?start=ref_...`) + پاداش کیف پول + تخفیف دعوت‌شونده
- 💰 **کیف پول** با تاریخچه تراکنش‌ها
- 📞 پشتیبانی

### ادمین (دکمه «⚙️ پنل مدیریت» در کیبورد — فقط برای مدیرها)
- 📊 **آمار**: کاربران، سفارش‌ها، درآمد، رسیدهای در انتظار
- 📦 **سفارش‌ها**: فیلتر بر اساس وضعیت، مشاهده جزئیات، دانلود فایل‌ها، تغییر وضعیت (تأیید پیش‌پرداخت → در حال انجام → تکمیل → تسویه)
- 💳 **پرداخت‌ها**: لیست + تأیید/رد رسید + مشاهده رسید
- 🗂 **دسته‌بندی‌ها**: افزودن، تغییر قیمت، تغییر درصد پیش‌پرداخت، فعال/غیرفعال
- ⚙️ **تنظیمات**: روشن/خاموش پیش‌پرداخت، درصد پیش‌پرداخت، تعداد سفارش‌های نمایش به مشتری، شماره کارت و اطلاعات بانکی، پاداش دعوت، تخفیف، پشتیبانی
- 📣 **پیام همگانی** به همه کاربران
- 👥 **کاربران**
- 🔔 **اعلان‌ها**: ویرایش پیام‌های هر وضعیت سفارش

## 🚀 نصب و اجرا

```bash
pip install -r requirements.txt
cp .env.example .env   # توکن و آیدی ادمین را وارد کنید
python3 main.py
```

### متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather |
| `ADMIN_USER_IDS` | آیدی عددی تلگرام مدیرها، با کاما جدا |
| `BOT_USERNAME` | نام ربات بدون `@` (اختیاری — برای لینک معرف) |
| `WEBAPP_PORT` | پورت سرور (پیش‌فرض 5000) |
| `DATABASE_PATH` / `UPLOAD_FOLDER` | مسیر دیتابیس و فایل‌ها (اختیاری) |

## 🖥 استقرار روی Render

1. پروژه را به GitHub بفرستید و Web Service جدید بسازید (فایل `render.yaml` آماده است).
2. متغیرهای `BOT_TOKEN` و `ADMIN_USER_IDS` را ست کنید (و `BOT_USERNAME` برای لینک معرف).
3. ربات را `/start` کنید؛ ادمین‌ها دکمه «⚙️ پنل مدیریت» را در کیبورد می‌بینند.

> 😴 سرویس فری Render بعد از ~۱۵ دقیقه بدون ترافیک می‌خوابد. با [cron-job.org](https://cron-job.org) هر ۱۰ دقیقه به `https://your-app.onrender.com/` پینگ بزنید.
>
> ⚠️ فایل‌سیستم Render موقتی است؛ دیتابیس با هر دیپلوی دوباره پاک می‌شود. برای ماندگاری دیتا، پلن پولی + Persistent Disk و `DATABASE_PATH=/var/data/database.json` و `UPLOAD_FOLDER=/var/data/uploads`.

## 🧾 چرخه پرداخت دستی

1. مشتری سفارش ثبت می‌کند → پس از آپلود فایل‌ها، شماره کارت و مبلغ برایش ارسال می‌شود.
2. پس از واریز، دکمه «🧾 ارسال رسید پرداخت» → عکس رسید را می‌فرستد.
3. رسید برای ادمین ارسال می‌شود (دکمه تأیید/رد همان‌جا).
4. پس از تأیید، وضعیت سفارش به‌روزرسانی و به مشتری اطلاع داده می‌شود.

## 📂 ساختار

```
main.py       — ربات + سرور Flask (فقط health برای Render)
database.json — دیتابیس (خودکار ساخته می‌شود)
uploads/      — فایل‌های آپلودی
```
